
اختبار المشروع: 
تم اختبار المشروع عبر المتصفح (Chrome / Edge) للتأكد من:
- عمل الميكروفون  
- ظهور الرسائل الصوتية  
- عدم وجود أخطاء اتصال بالخادم  
- عمل واجهة المساعد الصوتي بشكل كامل

طريقة التشغيل:
1. افتح الرابط الخاص بالموقع على الاستضافة  
2. اضغط على زر الميكروفون  
3. تحدث ليبدأ المساعد الصوتي بالاستجابة  
4. في حال حدوث خطأ، سيظهر تنبيه لإعادة المحاولة
